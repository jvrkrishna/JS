# 📘 JavaScript – Introduction

## 🌟 What is JavaScript?
**JavaScript** is a programming language used to make web pages **interactive** and **dynamic**.

It allows websites to:
- ✅ Respond to user actions
- ✅ Display dynamic content
- ✅ Perform calculations
- ✅ Create animations
- ✅ Build interactive web applications

# 🌐 Role of JavaScript in Web Development
Web pages are built using three main technologies.

| Technology | Purpose |
|------------|---------|
| **HTML** | Provides the structure (Skeleton) |
| **CSS** | Provides styling (Design & Layout) |
| **JavaScript** | Adds functionality and interactivity |

### Example
- HTML → Creates a button
- CSS → Styles the button
- JavaScript → Makes the button perform an action when clicked

# 💡 Where is JavaScript Used?
## 1️⃣ Frontend Development (Browser)
JavaScript runs inside web browsers such as:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

Common uses:
- Button click events
- Form validation
- Image sliders
- Navigation menus
- Pop-up messages
- Animations

## 2️⃣ Backend Development (Server)
Using **Node.js**, JavaScript can also run on the server.

It can be used to:
- Create web servers
- Connect to databases
- Build REST APIs
- Handle user authentication

## 3️⃣ Other Applications
JavaScript is also used for developing:
- 📱 Mobile applications
- 💻 Desktop applications
- 🎮 Games
- 🤖 AI-powered tools
- 🌐 IoT (Internet of Things) applications

# ⚙️ How JavaScript Works
The browser performs the following steps:
```
Browser loads the webpage
        ↓
Reads the JavaScript code
        ↓
Executes the code
        ↓
Displays the result
```

# 👨‍💻 Your First JavaScript Program
```javascript
console.log("Hello World");
```

### Explanation
- **console** → Browser's developer console
- **log()** → Displays output in the console

Output:
```
Hello World
```

# 🖥️ Where to Write JavaScript Code
## ✅ Method 1: Browser Console (Best for Beginners)
### Steps
1. Open Google Chrome
2. Right-click anywhere on the page
3. Select **Inspect**
4. Open the **Console** tab
5. Type JavaScript code and press **Enter**

## ✅ Method 2: Code Editor + Browser
Popular code editors:
- Visual Studio Code (VS Code)
- Sublime Text
- Notepad++
- WebStorm

Write your code in a file and open it in a browser.
# 📄 JavaScript Inside HTML
```html
<script>
alert("Welcome to JavaScript!");
</script>
```

The `<script>` tag is used to write JavaScript inside an HTML document.

# 📄 Sample HTML File
**sample.html**
```html
<!DOCTYPE html>
<html>
<head>
    <title>JavaScript Alert</title>
</head>
<body>
    <h1>Welcome to JavaScript</h1>

    <script>
        alert("Welcome to JavaScript!");
    </script>
</body>
</html>
```

# ✍️ Practice
```javascript
console.log("My name is ______");

console.log("I am learning JavaScript");
```

# 🧠 JavaScript Syntax Example
```html
<!DOCTYPE html>
<html>
<head>
    <title>JavaScript Syntax</title>
    <script>
        document.write("Hi! This is a sample program.");
    </script>
</head>
<body>
</body>
</html>
```

> **Note:** `document.write()` is mainly used for learning and simple demonstrations. It is **not recommended** in modern web development because it can overwrite the entire webpage if used after the page has loaded.

# 📌 Three Ways to Include JavaScript
## 1️⃣ Inside the `<head>` Tag
```html
<head>
<script>
console.log("Hello");
</script>
</head>
```

## 2️⃣ Inside the `<body>` Tag
```html
<body>
<script>
console.log("Hello");
</script>
</body>
```

## 3️⃣ Using an External JavaScript File (Recommended)
Keeping JavaScript in a separate file makes code easier to maintain and reuse.

# 📌 Three Ways to Display Output
## 1️⃣ Using `document.write()`
```javascript
document.write("Hi! This is a sample program.");
```

**Purpose:** Learning and testing.

## 2️⃣ Using `alert()`
```javascript
alert("Hi! This is a sample program.");
```
or
```javascript
window.alert("Hi! This is a sample program.");
```

**Purpose:** Displays a pop-up message.

## 3️⃣ Using HTML + JavaScript (Recommended)
### HTML
```html
<p id="demo"></p>
```

### JavaScript
```javascript
document.getElementById("demo").innerHTML =
"This is used for displaying content.";
```

**Explanation**
- `getElementById()` selects an HTML element.
- `innerHTML` changes the content inside that element.

This is the most commonly used method for updating webpage content.
