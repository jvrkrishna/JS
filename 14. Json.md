# 📘 JSON (JavaScript Object Notation)

# 🌟 What is JSON?
**JSON (JavaScript Object Notation)** is a lightweight text format used to **store** and **transfer** data.

Although JSON is based on JavaScript object syntax, it is **not JavaScript**.

JSON is widely used in:
- Web APIs
- Local Storage
- Server communication
- Configuration files
- Data exchange between applications

# ❓ Why Do We Use JSON Instead of JavaScript?

Although JSON looks similar to JavaScript objects, they serve different purposes.

## 1️⃣ JavaScript is a Programming Language

JavaScript can:
- Create functions
- Execute code
- Use loops and conditions
- Manipulate the DOM
- Handle events

JSON:
- Stores only data
- Cannot execute code
- Cannot contain functions

## JavaScript Object

```javascript
let student = {
    name: "John",

    greet: function() {
        console.log("Hello");
    }
};
```

## JSON

```json
{
    "name": "John"
}
```

> **Note:** JSON cannot contain functions.

# 2️⃣ JSON Works with All Programming Languages

JavaScript objects can only be used in JavaScript.

JSON can be used by many programming languages, including:

- Python
- Java
- PHP
- C#
- Node.js
- Mobile applications
- Databases
- Web servers

This is why APIs use JSON to exchange data.

# 3️⃣ JSON Is Safer

If a server sent JavaScript code instead of JSON:

- It could execute unwanted or malicious code.
- It would create security risks.

JSON is simply **text data** and does not execute code.

# 4️⃣ JSON Is a Standard Data Format

JSON follows strict rules, making it reliable for communication.

JSON requires:

- Double quotes around keys
- Double quotes around string values
- No functions
- No comments

# 📂 Why is JSON Important?

- ✅ Used by Web APIs
- ✅ Used in Local Storage
- ✅ Used for client-server communication
- ✅ Easy to share data between different programming languages
- ✅ Lightweight compared to XML
- ✅ Easy to read and write

# 📌 JSON Rules

A valid JSON document follows these rules:

- ✔ Data is stored as key-value pairs.
- ✔ Keys must be enclosed in double quotes.
- ✔ String values must use double quotes.
- ✔ Items are separated using commas.
- ✔ Objects are enclosed in `{ }`.
- ✔ Arrays are enclosed in `[ ]`.

JSON does **not** support:

- ❌ Functions
- ❌ Comments
- ❌ `undefined`

# 📌 Difference Between JSON and JavaScript Object

| JavaScript Object | JSON |
|-------------------|------|
| Used inside JavaScript | Used for storing and transferring data |
| Keys may or may not use quotes | Keys must use double quotes |
| Can contain functions | Cannot contain functions |
| Can contain `undefined` | Cannot contain `undefined` |
| Can execute code | Cannot execute code |

# 🔄 JSON Methods in JavaScript

JavaScript provides two important methods for working with JSON.

## 1️⃣ `JSON.stringify()`

Converts a **JavaScript object** into a **JSON string**.

### Syntax

```javascript
JSON.stringify(object);
```

### Example

```javascript
let student = {
    name: "John",
    age: 20
};

let jsonData = JSON.stringify(student);

console.log(jsonData);
```

### Output

```
{"name":"John","age":20}
```

> **Use:** When sending data to a server or storing data in Local Storage.

# 2️⃣ `JSON.parse()`

Converts a **JSON string** into a **JavaScript object**.

### Syntax

```javascript
JSON.parse(jsonString);
```

### Example

```javascript
let jsonData = '{"name":"John","age":20}';

let student = JSON.parse(jsonData);

console.log(student.name);
```

### Output

```
John
```

> **Use:** When receiving data from a server or reading data from Local Storage.

# 📌 Complete Example

```javascript
// JavaScript Object
let student = {
    name: "John",
    age: 20
};

// Convert Object to JSON
let jsonData = JSON.stringify(student);

console.log("JSON String:", jsonData);

// Convert JSON back to Object
let obj = JSON.parse(jsonData);

console.log("Name:", obj.name);
```

### Output

```
JSON String: {"name":"John","age":20}
Name: John
```

# 💾 JSON with Local Storage

## Save Data

```javascript
let student = {
    name: "John",
    age: 20
};

localStorage.setItem(
    "student",
    JSON.stringify(student)
);
```

## Retrieve Data

```javascript
let data = JSON.parse(
    localStorage.getItem("student")
);

console.log(data.name);
```

### Output

```
John
```
