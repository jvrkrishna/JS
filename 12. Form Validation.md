# 📘 Form Validation in JavaScript

# 🌟 What is Form Validation?
**Form validation** is the process of checking user input before sending the data to the server.

It ensures that the entered data is correct, complete, and follows the required format.

### Benefits of Form Validation
- ✅ Prevents empty fields
- ✅ Ensures correct email format
- ✅ Validates password strength
- ✅ Improves data accuracy
- ✅ Enhances user experience

# 📂 Types of Form Validation

## 1️⃣ Client-side Validation
- Performed in the browser using JavaScript.
- Provides instant feedback to the user.
- Reduces unnecessary requests to the server.

## 2️⃣ Server-side Validation
- Performed on the server using backend languages such as PHP, Java, Python, or Node.js.
- More secure because users cannot bypass it.

> **Note:** Client-side validation improves the user experience, but server-side validation is always required for security.

# 🔎 Basic Form Validation

This example checks whether the name field is empty and allows only alphabetic characters.

```html
<!DOCTYPE html>
<html>
<body>

<form onsubmit="return validateForm()">
    Name:
    <input type="text" id="name">

    <br><br>

    <input type="submit" value="Submit">
</form>

<script>
function validateForm() {

    let name = document.getElementById("name").value;

    // Only letters (A-Z, a-z)
    let pattern = /^[A-Za-z]+$/;

    if (name === "") {
        alert("Name cannot be empty.");
        return false;
    }

    if (!pattern.test(name)) {
        alert("Only letters are allowed. Numbers and special characters are not permitted.");
        return false;
    }

    return true;
}
</script>

</body>
</html>
```

# 📌 Regular Expression Used

```javascript
/^[A-Za-z]+$/
```

### Explanation

| Symbol | Meaning |
|--------|---------|
| `^` | Start of the string |
| `[A-Za-z]` | Allows uppercase and lowercase letters |
| `+` | One or more letters are required |
| `$` | End of the string |

The input must contain **only alphabetic characters**.


# 🔎 Advanced Form Validation
<!DOCTYPE html>
<html>
<head>
<style>
.error {
    border: 2px solid red;
}

.success {
    border: 2px solid green;
}

#errorMsg {
    color: red;
    font-size: 14px;
    margin-top: 5px;
}
</style>
</head>
<body>

<form onsubmit="return validateForm()">
    Name:
    <input type="text" id="name">
    <div id="errorMsg"></div>

    <br>
    <input type="submit" value="Submit">
</form>

<script>
function validateForm() {

    let name = document.getElementById("name");
    let errorMsg = document.getElementById("errorMsg");

    let value = name.value.trim();

    // Only letters, 3 to 15 characters
    let pattern = /^[A-Za-z]{3,15}$/;

    // Reset
    name.classList.remove("error", "success");
    errorMsg.innerHTML = "";

    if (value === "") {
        name.classList.add("error");
        errorMsg.innerHTML = "Name cannot be empty.";
        return false;
    }

    if (!pattern.test(value)) {
        name.classList.add("error");
        errorMsg.innerHTML = "Name must contain only letters and be 3 to 15 characters.";
        return false;
    }

    name.classList.add("success");
    return true;
}
</script>

</body>
</html>


# 📧 Email Validation

The following example validates an email address.

```html
<!DOCTYPE html>
<html>
<body>

<form onsubmit="return validateEmail()">
    Email:
    <input type="text" id="email">

    <br><br>

    <input type="submit" value="Submit">
</form>

<script>
function validateEmail() {

    let email = document.getElementById("email").value;

    // Format: text@text.text
    let pattern = /^[^ ]+@[^ ]+\.[^ ]+$/;

    if (!pattern.test(email)) {
        alert("Enter a valid email address (Example: name@gmail.com).");
        return false;
    }

    return true;
}
</script>

</body>
</html>
```

# 📌 Regular Expression Used

```javascript
/^[^ ]+@[^ ]+\.[^ ]+$/
```

### Explanation

| Symbol | Meaning |
|--------|---------|
| `^` | Start of the string |
| `[^ ]+` | One or more characters except spaces |
| `@` | Must contain the `@` symbol |
| `\.` | Represents a literal dot (`.`) |
| `$` | End of the string |

The email must follow this format:

```
something@something.something
```

### Examples

| Input | Result |
|--------|--------|
| `john@gmail.com` | ✅ Valid |
| `student@yahoo.in` | ✅ Valid |
| `john@gmail` | ❌ Invalid |
| `john.com` | ❌ Invalid |
| `john @gmail.com` | ❌ Invalid |

# 🔐 Password Validation

The following example checks whether a password is strong.

```html
<!DOCTYPE html>
<html>
<body>

<form onsubmit="return validatePassword()">
    Password:
    <input type="password" id="pass">

    <br><br>

    <input type="submit" value="Submit">
</form>

<script>
function validatePassword() {

    let pass = document.getElementById("pass").value;

    // Strong password
    let pattern = /^(?=.*[A-Z])(?=.*[0-9])(?=.*[!@#$%^&*])[A-Za-z0-9!@#$%^&*]{6,}$/;

    if (!pattern.test(pass)) {
        alert("Password must contain at least 6 characters, one uppercase letter, one number, and one special character.");
        return false;
    }

    return true;
}
</script>

</body>
</html>
```

# 📌 Regular Expression Used

```javascript
/^(?=.*[A-Z])(?=.*[0-9])(?=.*[!@#$%^&*])[A-Za-z0-9!@#$%^&*]{6,}$/
```

### Explanation

| Symbol | Meaning |
|--------|---------|
| `^` | Start of the string |
| `(?=.*[A-Z])` | At least one uppercase letter |
| `(?=.*[0-9])` | At least one digit |
| `(?=.*[!@#$%^&*])` | At least one special character |
| `[A-Za-z0-9!@#$%^&*]` | Allowed characters |
| `{6,}` | Minimum 6 characters |
| `$` | End of the string |

### Examples

| Password | Result |
|-----------|--------|
| `Abc@123` | ✅ Valid |
| `Java@1` | ✅ Valid |
| `abc123` | ❌ No uppercase letter or special character |
| `ABC123` | ❌ No special character |
| `Abc@` | ❌ Less than 6 characters |

# 📌 `test()` Method

The `test()` method checks whether a string matches a regular expression.

## Syntax

```javascript
pattern.test(string);
```

### Example

```javascript
let pattern = /^[A-Za-z]+$/;

console.log(pattern.test("John"));
console.log(pattern.test("John123"));
```

### Output

```
true
false
```
