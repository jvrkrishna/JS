Form Validation in JavaScript

🌟 What is Form Validation?

Form validation is the process of checking user input before sending data to the server.

👉 It ensures data is correct and complete.
👉 Prevents wrong or empty data submission.

📂 Why Form Validation is Important?

✅ Prevent empty fields
✅ Ensure correct email format
✅ Ensure password rules
✅ Improve data accuracy
✅ Improve user experience

🧾 Types of Form Validation

1️⃣ Client-side Validation (JavaScript)
2️⃣ Server-side Validation (Backend)

👉 In this lesson, we focus on Client-side Validation.

🔎 Basic Form Validation Example

<form onsubmit="return validateForm()">

Name: <input type="text" id="name">

<br><br>

<input type="submit" value="Submit">

</form>

<script>

function validateForm() {

let name = document.getElementById("name").value;

// Only alphabets allowed (A-Z, a-z)

let pattern = /^[A-Za-z]+$/;

if(name == "") {

alert("Name cannot be empty");

return false;

}

if(!pattern.test(name)) {

alert("Only letters are allowed. No numbers or special characters.");

return false;

}

return true;

}

</script>

Explanation:

/^[A-Za-z]+$/

^ → Start of string

[A-Za-z] → Only letters (capital and small)

+ → One or more letters required

$ → End of string

📧 Email Validation Example

<form onsubmit="return validateEmail()">

Email: <input type="text" id="email">

<br><br>

<input type="submit">

</form>

<script>

function validateEmail() {

let email = document.getElementById("email").value;

// pattern: text@text.text

let pattern = /^[^ ]+@[^ ]+\.[^ ]+$/;

if(!pattern.test(email)) {

alert("Enter valid email (example: name@gmail.com)");

return false;

}

return true;

}

</script>

Explanation:

/^[^ ]+@[^ ]+\.[^ ]+$/

/ / → These are just start and end markers of a regex in JavaScript.

^ → Start of the string

[^ ]+ → One or more characters that are NOT a space (text before @)

@ → Must contain the @ symbol

[^ ]+ → One or more characters that are NOT a space (text after @)

\. → A literal dot (.)

[^ ]+ → One or more characters that are NOT a space (text after dot)

$ → End of the string

Overall meaning:

The string must follow this format:

something@something.something

with no spaces and at least one character in each section.

🔐 Password Validation Example

<form onsubmit="return validatePassword()">

Password: <input type="password" id="pass">

<br><br>

<input type="submit">

</form>

<script>

function validatePassword() {

let pass = document.getElementById("pass").value;

// Regex for strong password

let pattern = /^(?=.*[A-Z])(?=.*[0-9])(?=.*[!@#$%^&*])[A-Za-z0-9!@#$%^&*]{6,}$/;

if(!pattern.test(pass)) {

alert("Password must be at least 6 characters and contain at least one uppercase letter, one number, and one special character.");

return false;

}

return true;

}

</script>

Explanation:
^ → Start of string

(?=.*[A-Z]) → At least one uppercase letter

(?=.*[0-9]) → At least one number

(?=.*[!@#$%^&*]) → At least one special character

[A-Za-z0-9!@#$%^&*] → Allowed characters

{6,} → Minimum 6 characters

$ → End of string
