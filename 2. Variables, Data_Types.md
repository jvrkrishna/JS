# 📘 Variables, Data Types, Comments & Template Literals

# 🌟 What is a Variable?
A **variable** is used to store data values.

👉 Think of a variable as a **container** that stores information.

### Example
```javascript
var name = "John";
```

Here:
- `name` → Variable name
- `"John"` → Stored value

# 🧾 Rules for Naming Variables
### ✅ Valid Rules
- Can contain letters, numbers, `_`, and `$`
- Must start with a letter, `_`, or `$`
- Variable names are case-sensitive (`age` and `Age` are different)

### ❌ Invalid Rules
- Cannot start with a number
- Cannot use JavaScript keywords as variable names
- Cannot contain spaces

### ✅ Valid Examples
```javascript
var age;
var _total;
var $price;
var user1;
```

### ❌ Invalid Examples
```javascript
var 1name;
var var;
var first name;
```

# 📦 Ways to Declare Variables

## 1️⃣ `var` (Older Method)
```javascript
var age = 25;
```

**Characteristics:**
- Function scoped
- Can be redeclared
- Can be reassigned
- Avoid using `var` in modern JavaScript unless necessary

## 2️⃣ `let` (Recommended)
```javascript
let age = 25;
```

**Characteristics:**
- Block scoped
- Cannot be redeclared in the same scope
- Can be reassigned

## 3️⃣ `const` (Constant Value)
```javascript
const pi = 3.14;
```

**Characteristics:**
- Block scoped
- Cannot be redeclared
- Cannot be reassigned

> **Note:** A `const` variable must be initialized when it is declared.

```javascript
const pi = 3.14;
pi = 3.14159; // ❌ TypeError
```


# 1️⃣ Scope Difference (`var` vs `let`)

## `var` → Function Scoped
A variable declared with `var` is accessible throughout the function in which it is declared.

```javascript
function testVar() {
    if (true) {
        var x = 10;
    }

    console.log(x); // ✅ 10
}

testVar();
```

## `let` → Block Scoped
A variable declared with `let` is accessible only inside the block (`{}`) where it is declared.

```javascript
function testLet() {
    if (true) {
        let y = 20;
    }

    console.log(y); // ❌ ReferenceError
}

testLet();
```

# 2️⃣ Hoisting Difference
Both `var` and `let` are hoisted, but they behave differently.

### `var`
```javascript
console.log(a);

var a = 5;
```

Output:
```
undefined
```

`var` is hoisted and initialized with `undefined`.

### `let`
```javascript
console.log(b);

let b = 10;
```

Output:
```
ReferenceError
```

`let` is hoisted but remains in the **Temporal Dead Zone (TDZ)** until it is declared.

# 3️⃣ Redeclaration Rules

## `var`
```javascript
var name = "Alex";
var name = "Sam";

console.log(name);
```

Output:
```
Sam
```

Redeclaration is allowed.

## `let`
```javascript
let age = 25;
let age = 30;
```

Output:
```
SyntaxError
```

Redeclaration is not allowed in the same scope.

# 4️⃣ Global Object Behaviour

When variables are declared globally in a browser:

- `var` becomes a property of the `window` object.
- `let` and `const` do not become properties of the `window` object.

```javascript
var a = 1;
let b = 2;

console.log(window.a); // 1
console.log(window.b); // undefined
```

# 5️⃣ Loop Example (Important)

## Using `var`
```javascript
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100);
}


for (var i = 0; i < 3; i++) {
    console.log(i);
    setTimeout(() => console.log(i), 100);
}
```

Output:
```
3
3
3
```

## Using `let`
```javascript
for (let j = 0; j < 3; j++) {
    setTimeout(() => console.log(j), 100);
}
```

Output:
```
0
1
2
```

**Reason:** `let` creates a new variable for each iteration of the loop.

# 🔢 JavaScript Data Types

JavaScript has two categories of data types:

- Primitive Data Types
- Non-Primitive (Reference) Data Types

## Primitive Data Types

### 1️⃣ Number
```javascript
let age = 25;
let price = 99.99;
```

Represents both integers and decimal numbers.

### 2️⃣ String
```javascript
let name = "John";
let city = 'London';
```

Represents text.

### 3️⃣ Boolean
```javascript
let isActive = true;
let isAdmin = false;
```

Represents either `true` or `false`.

### 4️⃣ Undefined
```javascript
let x;
```

A variable that has been declared but not assigned a value.

### 5️⃣ Null
```javascript
let data = null;
```

Represents an intentional empty value.

### 6️⃣ BigInt
```javascript
let num = 12345678901234567890n;
```

Used for very large integers.

# 7️⃣ What is a Symbol?

A **Symbol** is a **primitive data type** in JavaScript that represents a **unique** and **immutable (cannot be changed)** value.

- Every Symbol is unique.
- Even if two Symbols have the same description, they are **never equal**.
- Symbols are commonly used as **unique object property keys** to avoid property name conflicts.

---

## Creating a Symbol

### Syntax

```javascript
let id = Symbol("id");

console.log(id);
console.log(typeof id);
```

### Output

```javascript
Symbol(id)
symbol
```

### Explanation

- `"id"` is only a **description** used for debugging.
- It **does not** determine the Symbol's identity.
- The data type returned by `typeof` is `"symbol"`.

---

# Every Symbol is Unique

```javascript
let s1 = Symbol("id");
let s2 = Symbol("id");

console.log(s1 == s2);
```

### Output

```javascript
false
```

### Explanation

Although both Symbols have the same description (`"id"`), they are completely different values.

```
Symbol("id") !== Symbol("id")
```

Every call to `Symbol()` creates a brand-new unique Symbol.

---

# Using Symbol as an Object Property

## Using a Normal Property

```javascript
let student = {};

student.id = 101;

console.log(student);
```

### Output

```javascript
{ id: 101 }
```

Here, `"id"` is a **string property name**.

---

## Using a Symbol Property

```javascript
let id = Symbol();

let student = {};

student[id] = 101;

console.log(student);
```

### Output

```javascript
{ [Symbol()]: 101 }
```

### Explanation

- The property key is a **Symbol**, not a string.
- Symbol keys help prevent accidental property name collisions.

---

# Accessing a Symbol Property

```javascript
let id = Symbol();

let obj = {};

obj[id] = 100;

console.log(obj[id]);
```

### Output

```javascript
100
```

---

# Symbol Keys Must Use Bracket Notation

## Correct

```javascript
obj[id];
```

## Wrong

```javascript
obj.id;
```

### Why?

```javascript
obj.id
```

looks for a **string property** named `"id"`.

However,

```javascript
obj[id]
```

uses the Symbol stored in the variable `id` as the property key.

---

# Symbol Properties Are Hidden

```javascript
let id = Symbol();

let student = {
    name: "John"
};

student[id] = 101;

console.log(Object.keys(student));
```

### Output

```javascript
["name"]
```

### Explanation

`Object.keys()` returns only **string-keyed enumerable properties**.

The Symbol property is **hidden** and is **not included** in the result.

---

# Why Use Symbols?

Symbols are useful when you want:

- ✅ Unique property names
- ✅ To avoid property name conflicts
- ✅ Hidden object properties
- ✅ Internal object metadata

---

# Key Points

- `Symbol()` creates a unique value.
- Symbols are immutable.
- Two Symbols with the same description are **never equal**.
- Symbol descriptions are only for debugging.
- Symbols can be used as object property keys.
- Symbol properties must be accessed using **bracket notation (`[]`)**.
- Symbol properties are ignored by `Object.keys()` and are hidden from normal property enumeration.

---

# Summary

| Feature | Description |
|---------|-------------|
| Data Type | Primitive |
| Immutable | ✅ Yes |
| Unique | ✅ Every Symbol is unique |
| Property Key | ✅ Yes |
| Access Method | `obj[symbol]` |
| Hidden from `Object.keys()` | ✅ Yes |
| Prevents Property Conflicts | ✅ Yes |

---

## Example

```javascript
let id = Symbol("id");

let student = {
    name: "John"
};

student[id] = 101;

console.log(student.name);       // John
console.log(student[id]);        // 101
console.log(Object.keys(student)); // ["name"]
```

### Output

```javascript
John
101
["name"]
```

# 🧵 Template Literals
Template literals provide an easier way to create strings.

Instead of using:
```javascript
""
''
```

Template literals use **backticks (` `)**.

## ✨ Advantages
- Insert variables directly into strings.
- Create multi-line strings easily.
- Improve code readability.

# 📌 String Interpolation
Use `${}` to insert variables or expressions inside a template literal.

```javascript
let name = "John";
let age = 20;

console.log(`My name is ${name} and I am ${age} years old.`);
```

Output:
```
My name is John and I am 20 years old.
```

# 📌 Multi-line String Example

```javascript
let message = `Welcome
to
JavaScript`;

console.log(message);
```

Output:
```
Welcome
to
JavaScript
```

# 🧪 Example: Template Literal
```html
<script>
let a = Number(prompt("Enter first value"));
let b = Number(prompt("Enter second value"));

document.write(`Sum of ${a} and ${b} is ${a + b}`);
</script>
```

# Example 1: Read Student Details Using `prompt()`
### Code
```javascript
let name = prompt("Enter student name:");
let age = Number(prompt("Enter student age:"));

let student = {
    name: name,
    age: age
};

console.log(student);
```

### Sample Input
```
Enter student name: John
Enter student age: 20
```

### Output
```text
{
  name: "John",
  age: 20
}
```

### Explanation
- `prompt("Enter student name:")` asks the user to enter the student's name.
- `prompt("Enter student age:")` asks the user to enter the student's age.
- `Number()` converts the entered age from a string to a number.
- A `student` object is created using the entered values.
- `console.log(student)` displays the object in the browser console.

# Example 2: Check Whether the User Clicked **Cancel**
### Code
```javascript
let name = prompt("Enter your name:");

if (name !== null) {
    console.log("Welcome", name);
} else {
    console.log("User cancelled the input.");
}
```

### Sample Input
```
Enter your name: Alice
```

### Output
```text
Welcome Alice
```

### If the User Clicks **Cancel**
### Output
```text
User cancelled the input.
```

### Explanation
- `prompt("Enter your name:")` displays an input dialog.
- If the user enters a name and clicks **OK**, `prompt()` returns the entered text.
- If the user clicks **Cancel**, `prompt()` returns `null`.
- The `if` statement checks whether the returned value is `null`.
- If it is not `null`, the program displays a welcome message; otherwise, it informs that the user cancelled the input.
