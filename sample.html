Without a form Clicking the button simply calls saveData(). There is no form submission. The page stays as it is. With a form
Clicking Save submits the form. The browser tries to send the form data and reloads the page. To stop that behavior, use: event.preventDefault(); Why use a
? A groups related input fields together. It is the standard HTML element for collecting user input. It provides: Better organization of input fields. Built-in validation (such as required, type="email", etc.). Easy submission of data to a server. Better accessibility and browser support. Which one should you use? Learning JavaScript or small demos: Use without because it's simpler. Registration forms, login pages, contact forms, or real applications: Use with because it's the standard and recommended approach.
