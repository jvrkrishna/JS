# 📘 Events in JavaScript

# 🌟 What is an Event?
An **event** is an action or occurrence that happens in the browser.

Events can be triggered by:

- **User actions** (click, hover, key press, form submission)
- **Browser actions** (page load, resize, scroll)

JavaScript listens for these events and executes code when they occur.

# 📂 Common JavaScript Events

| Event | Description |
|--------|-------------|
| `onclick` | Triggered when an element is clicked |
| `onmouseover` | Triggered when the mouse pointer enters an element |
| `onmouseout` | Triggered when the mouse pointer leaves an element |
| `onkeydown` | Triggered when a keyboard key is pressed |
| `onload` | Triggered when the page finishes loading |
| `onchange` | Triggered when an input value changes |
| `onsubmit` | Triggered when a form is submitted |

# 1️⃣ `onclick` Event

## Use
- Triggered when the user clicks an element.
- Commonly used with buttons, links, and images.

## Example 1 – Display an Alert

```html
<!DOCTYPE html>
<html>
<body>

<button onclick="showMessage()">Click Me</button>

<script>
function showMessage() {
    alert("Button Clicked");
}
</script>

</body>
</html>
```

### Output
```
An alert displays "Button Clicked".
```

## Example 2 – Change Text

```html
<!DOCTYPE html>
<html>
<body>

<p id="demo">Click This Paragraph</p>

<button onclick="changeText()">Change Text</button>

<script>
function changeText() {
    document.getElementById("demo").innerHTML = "Text Changed!";
}
</script>

</body>
</html>
```

### Output
```
The paragraph text changes to "Text Changed!".
```

## Example 3 – Change Background Color

```html
<!DOCTYPE html>
<html>
<body>

<button onclick="changeStyle()">Click Me</button>

<script>
function changeStyle() {
    document.body.style.backgroundColor = "lightgreen";
}
</script>

</body>
</html>
```

### Output
```
The page background changes to light green.
```

# 2️⃣ `onmouseover` Event

## Use
- Triggered when the mouse pointer moves over an element.

## Example 1 – Change Text on Hover

```html
<!DOCTYPE html>
<html>
<body>

<p onmouseover="hoverText(this, 'You hovered over me!')">Hover 1</p>
<p onmouseover="hoverText(this, 'Welcome!')">Hover 2</p>

<script>
function hoverText(element, message) {
    element.innerHTML = message;
}
</script>

</body>
</html>
```

### Output
```
The paragraph text changes when the mouse hovers over it.
```

## Example 2 – Change Style on Hover

```html
<!DOCTYPE html>
<html>
<body>

<p onmouseover="hoverStyle(this)"
   onmouseout="resetStyle(this)">
    Hover Here
</p>

<script>
function hoverStyle(element) {
    element.style.color = "red";
    element.style.fontWeight = "bold";
}

function resetStyle(element) {
    element.style.color = "black";
    element.style.fontWeight = "normal";
}
</script>

</body>
</html>
```

### Output
```
The text becomes red and bold on hover, then returns to normal when the mouse leaves.
```

## Example 3 – Display an Alert

```html
<!DOCTYPE html>
<html>
<body>

<div onmouseover="alert('Mouse is here!')">
    Hover Over Me
</div>

</body>
</html>
```

### Output
```
An alert appears when the mouse enters the div.
```

# 3️⃣ `onmouseout` Event

## Use
- Triggered when the mouse pointer leaves an element.

## Example

```html
<!DOCTYPE html>
<html>
<body>

<p onmouseover="this.style.color='blue'"
   onmouseout="this.style.color='black'">
    Hover and Leave
</p>

</body>
</html>
```

### Output
```
The text turns blue on hover and returns to black when the mouse leaves.
```

# 4️⃣ `onkeydown` Event

## Use
- Triggered when a key is pressed.
- Commonly used with input fields.

## Example 1 – Log a Key Press

```html
<!DOCTYPE html>
<html>
<body>

<input type="text" onkeydown="keyPressed()">

<script>
function keyPressed() {
    console.log("Key Pressed");
}
</script>

</body>
</html>
```

### Output
```
"Key Pressed" is displayed in the console for every key press.
```

## Example 2 – Display the Pressed Key

```html
<!DOCTYPE html>
<html>
<body>

<p id="output"></p>

<input type="text" onkeydown="showKey(event)">

<script>
function showKey(event) {
    document.getElementById("output").innerHTML =
    "Key: " + event.key;
}
</script>

</body>
</html>
```

### Output
```
Displays the key that was pressed.
```

## Example 3 – Detect the Enter Key

```html
<!DOCTYPE html>
<html>
<body>

<input type="text" onkeydown="checkEnter(event)">

<script>
function checkEnter(event) {
    if (event.key === "Enter") {
        alert("Enter Pressed!");
    }
}
</script>

</body>
</html>
```

### Output
```
An alert appears when the Enter key is pressed.
```

# 7️⃣ `onsubmit` Event

## Use
- Triggered when a form is submitted.
- Commonly used for form validation.

## Example 1 – Display an Alert

```html
<!DOCTYPE html>
<html>
<body>

<form onsubmit="submitForm()">
    <input type="submit">
</form>

<script>
function submitForm() {
    alert("Form Submitted");
}
</script>

</body>
</html>
```

### Output
```
An alert appears when the form is submitted.
```

## Example 2 – Validate Form Input

```html
<!DOCTYPE html>
<html>
<body>

<form onsubmit="return validateForm()">
    <input type="text" id="name">
    <input type="submit">
</form>

<script>
function validateForm() {
    let name = document.getElementById("name").value;

    if (name === "") {
        alert("Name is required!");
        return false;
    }

    alert("Form Submitted Successfully");
    return true;
}
</script>

</body>
</html>
```

### Output
```
Displays a warning if the input is empty; otherwise, the form is submitted.
```

## Example 3 – Change Page Content

```html
<!DOCTYPE html>
<html>
<body>

<form onsubmit="changeContent(); return false;">
    <input type="submit">
</form>

<p id="demo"></p>

<script>
function changeContent() {
    document.getElementById("demo").innerHTML =
    "Thank you for submitting!";
}
</script>

</body>
</html>
```

### Output
```
The paragraph displays a thank-you message.
```

# 8️⃣ `addEventListener()`

## Use
- The modern and recommended way to handle events.
- Allows multiple event listeners on the same element.
- Keeps JavaScript separate from HTML.

## Syntax

```javascript
element.addEventListener("event", function() {
    // Code to execute
});
```

## Example 1 – Click Event

```html
<!DOCTYPE html>
<html>
<body>

<button id="btn">Click Me</button>

<script>
document.getElementById("btn").addEventListener("click", function() {
    alert("Button Clicked");
});
</script>

</body>
</html>
```

## Example 2 – Mouseover Event

```html
<!DOCTYPE html>
<html>
<body>

<p id="demo">Hover Here</p>

<script>
document.getElementById("demo").addEventListener("mouseover", function() {
    this.innerHTML = "Hovered!";
});
</script>

</body>
</html>
```

## Example 3 – Change Event

```html
<!DOCTYPE html>
<html>
<body>

<input type="text" id="name">

<script>
document.getElementById("name").addEventListener("change", function() {
    console.log("Value Changed");
});
</script>

</body>
</html>
```
