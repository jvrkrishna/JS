# 📘 Arrays in JavaScript

# 🌟 What is an Array?
An **array** is a special variable that can store **multiple values** in a single variable.

Instead of creating many separate variables, we can store related values together in an array.

### Without an Array
```javascript
let student1 = "John";
let student2 = "Mary";
let student3 = "David";
```

### With an Array
```javascript
let students = ["John", "Mary", "David"];
```

# 📦 Creating Arrays

## 1️⃣ Using Square Brackets (Recommended)

```javascript
let fruits = ["Apple", "Banana", "Mango"];
```

## 2️⃣ Using the Array Constructor

```javascript
let fruits = new Array("Apple", "Banana", "Mango");
```

> **Note:** Using square brackets (`[]`) is the recommended and most commonly used method.

# 🔢 Array Index
Each element in an array has an **index**.

- Array indexing starts from **0**.
- The first element has index `0`.
- The second element has index `1`.

## Example

```javascript
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits[0]);
console.log(fruits[1]);
console.log(fruits[2]);
```

### Output
```
Apple
Banana
Mango
```

# 📏 Array Length
The `length` property returns the total number of elements in an array.

## Example

```javascript
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.length);
```

### Output
```
3
```

# ✏️ Modifying Array Elements
Array elements can be modified using their index.

## Example

```javascript
let fruits = ["Apple", "Banana", "Mango"];

fruits[1] = "Orange";

console.log(fruits);
```

### Output
```
["Apple", "Orange", "Mango"]
```

# ➕ Adding Elements to an Array

## `push()`
Adds one or more elements to the **end** of the array.

```javascript
let fruits = ["Apple", "Banana"];

fruits.push("Mango");

console.log(fruits);
```

### Output
```
["Apple", "Banana", "Mango"]
```

## `unshift()`
Adds one or more elements to the **beginning** of the array.

```javascript
let fruits = ["Apple", "Banana"];

fruits.unshift("Grapes");

console.log(fruits);
```

### Output
```
["Grapes", "Apple", "Banana"]
```

# ➖ Removing Elements from an Array

## `pop()`
Removes the **last** element from the array.

```javascript
let fruits = ["Apple", "Banana", "Mango"];

fruits.pop();

console.log(fruits);
```

### Output
```
["Apple", "Banana"]
```

## `shift()`
Removes the **first** element from the array.

```javascript
let fruits = ["Apple", "Banana", "Mango"];

fruits.shift();

console.log(fruits);
```

### Output
```
["Banana", "Mango"]
```

# 🔍 Finding an Element

## Example

```javascript
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.indexOf("Banana"));
```

### Output
```
1
```

> **Note:** If the element is not found, `indexOf()` returns `-1`.

# 🔁 Looping Through Arrays

## Using `for` Loop

```javascript
let fruits = ["Apple", "Banana", "Mango"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
```

### Output
```
Apple
Banana
Mango
```

## Using `for...of` Loop

```javascript
let fruits = ["Apple", "Banana", "Mango"];

for (let fruit of fruits) {
    console.log(fruit);
}
```

### Output
```
Apple
Banana
Mango
```

## Using `forEach()`

```javascript
let fruits = ["Apple", "Banana", "Mango"];

fruits.forEach(function(item) {
    console.log(item);
});
```

### Output
```
Apple
Banana
Mango
```

# ⭐ Common Array Methods

| Method | Purpose |
|---------|---------|
| `push()` | Adds an element to the end |
| `pop()` | Removes the last element |
| `unshift()` | Adds an element to the beginning |
| `shift()` | Removes the first element |
| `length` | Returns the number of elements |
| `indexOf()` | Finds the index of an element |
| `includes()` | Checks whether an element exists |

# 📌 `includes()` Method
The `includes()` method checks whether an element exists in an array.

## Example

```javascript
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.includes("Banana"));
console.log(fruits.includes("Orange"));
```

### Output
```
true
false
```

# 📌 Arrays Can Store Different Data Types

```javascript
let data = [
    "John",
    25,
    true,
    95.5
];

console.log(data);
```

### Output
```
["John", 25, true, 95.5]
```
