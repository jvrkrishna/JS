# Form vs Without Form in HTML

## 1. Without `<form>`

### Example

```html
<body>

Name:
<input type="text" id="name"><br><br>

Email:
<input type="email" id="email"><br><br>

Password:
<input type="password" id="password"><br><br>

Phone:
<input type="text" id="phone"><br><br>

DOB:
<input type="date" id="dob"><br><br>

Gender:
<input type="radio" name="gender" value="Male">Male
<input type="radio" name="gender" value="Female">Female
<br><br>

<button onclick="saveData()">Save</button>
<button onclick="showData()">Show</button>
<button onclick="removeData()">Remove</button>

<br><br>

<div id="output"></div>

<script>
function saveData() {
    localStorage.setItem("name", document.getElementById("name").value);
    localStorage.setItem("email", document.getElementById("email").value);
    localStorage.setItem("password", document.getElementById("password").value);
    localStorage.setItem("phone", document.getElementById("phone").value);
    localStorage.setItem("dob", document.getElementById("dob").value);

    let gender = document.querySelector('input[name="gender"]:checked').value;
    localStorage.setItem("gender", gender);

    document.getElementById("output").innerHTML = "Data Saved Successfully!";
}

function showData() {
    document.getElementById("output").innerHTML =
        "Name: " + localStorage.getItem("name") + "<br>" +
        "Email: " + localStorage.getItem("email") + "<br>" +
        "Password: " + localStorage.getItem("password") + "<br>" +
        "Phone: " + localStorage.getItem("phone") + "<br>" +
        "DOB: " + localStorage.getItem("dob") + "<br>" +
        "Gender: " + localStorage.getItem("gender");
}

function removeData() {
    localStorage.clear();
    document.getElementById("output").innerHTML = "Data Removed Successfully!";
}
</script>

</body>
```

### How it works

```html
<input type="text" id="name">
<button onclick="saveData()">Save</button>
```

* Clicking the button simply calls `saveData()`.
* There is **no form submission**.
* The page **does not refresh**.
* `event.preventDefault()` is **not required**.

# 2. With `<form>`

### Example

```html
<body>

<form id="myForm">

Name:
<input type="text" id="name"><br><br>

Email:
<input type="email" id="email"><br><br>

Password:
<input type="password" id="password"><br><br>

Phone:
<input type="text" id="phone"><br><br>

DOB:
<input type="date" id="dob"><br><br>

Gender:
<input type="radio" name="gender" value="Male">Male
<input type="radio" name="gender" value="Female">Female
<br><br>

<button type="submit">Save</button>
<button type="button" onclick="showData()">Show</button>
<button type="button" onclick="removeData()">Remove</button>

</form>

<br>

<div id="output"></div>

<script>
document.getElementById("myForm").addEventListener("submit", function(event) {

    event.preventDefault();

    localStorage.setItem("name", document.getElementById("name").value);
    localStorage.setItem("email", document.getElementById("email").value);
    localStorage.setItem("password", document.getElementById("password").value);
    localStorage.setItem("phone", document.getElementById("phone").value);
    localStorage.setItem("dob", document.getElementById("dob").value);

    let gender = document.querySelector('input[name="gender"]:checked').value;
    localStorage.setItem("gender", gender);

    document.getElementById("output").innerHTML = "Data Saved Successfully!";
});

function showData() {
    document.getElementById("output").innerHTML =
        "Name: " + localStorage.getItem("name") + "<br>" +
        "Email: " + localStorage.getItem("email") + "<br>" +
        "Password: " + localStorage.getItem("password") + "<br>" +
        "Phone: " + localStorage.getItem("phone") + "<br>" +
        "DOB: " + localStorage.getItem("dob") + "<br>" +
        "Gender: " + localStorage.getItem("gender");
}

function removeData() {
    localStorage.clear();
    document.getElementById("output").innerHTML = "Data Removed Successfully!";
}
</script>

</body>
```

### How it works

```html
<form id="myForm">
    <input type="text" id="name">
    <button type="submit">Save</button>
</form>
```

* Clicking **Save** submits the form.
* The browser tries to send the form data and reload the page.
* To stop the page refresh, use:

```javascript
event.preventDefault();
```

---

# Why use a `<form>`?

A `<form>` groups related input fields together. It is the standard HTML element for collecting user input.

### Advantages

* Better organization of input fields.
* Built-in validation (`required`, `type="email"`, etc.).
* Easy submission of data to a server.
* Better accessibility and browser support.

---

# Difference Between With Form and Without Form

| Without `<form>`                        | With `<form>`                                           |
| --------------------------------------- | ------------------------------------------------------- |
| Uses `onclick` on buttons.              | Uses the `submit` event.                                |
| No page refresh.                        | Page refreshes by default after submit.                 |
| `event.preventDefault()` is not needed. | `event.preventDefault()` is needed to stop the refresh. |
| Suitable for small JavaScript examples. | Suitable for registration, login, and contact forms.    |

---

# Which one should you use?

### Use **Without `<form>`** when:

* Learning JavaScript.
* Creating small demos.
* Handling button clicks only.

### Use **With `<form>`** when:

* Creating registration forms.
* Creating login forms.
* Creating contact forms.
* Building real-world web applications.
