# 📘 Operators in JavaScript

# 🌟 What is an Operator?
An **operator** is a symbol used to perform operations on variables and values.

### Example
```javascript
let sum = 5 + 3;
```

Here:
- `+` → Operator
- `5` and `3` → Operands
- `sum` → Variable that stores the result

# 📂 Types of Operators in JavaScript
JavaScript provides several types of operators:

1. Arithmetic Operators
2. Assignment Operators
3. Comparison Operators
4. Logical Operators
5. Increment & Decrement Operators

# 🔢 1️⃣ Arithmetic Operators
Arithmetic operators are used to perform mathematical calculations.

| Operator | Meaning | Example |
|----------|---------|---------|
| `+` | Addition | `5 + 3` |
| `-` | Subtraction | `5 - 3` |
| `*` | Multiplication | `5 * 3` |
| `/` | Division | `10 / 2` |
| `%` | Modulus (Remainder) | `10 % 3` |
| `**` | Exponentiation (Power) | `2 ** 3` |

### Example
```javascript
let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** b);
```

### Output
```
15
5
50
2
0
100000
```

# 📝 2️⃣ Assignment Operators
Assignment operators are used to assign or update variable values.

| Operator | Example | Equivalent To |
|----------|---------|---------------|
| `=` | `x = 5` | Assign value |
| `+=` | `x += 3` | `x = x + 3` |
| `-=` | `x -= 3` | `x = x - 3` |
| `*=` | `x *= 3` | `x = x * 3` |
| `/=` | `x /= 3` | `x = x / 3` |
| `%=` | `x %= 3` | `x = x % 3` |
| `**=` | `x **= 2` | `x = x ** 2` |

### Example
```javascript
let x = 10;

x += 5;
console.log(x);

x *= 2;
console.log(x);
```

### Output
```
15
30
```

# ⚖️ 3️⃣ Comparison Operators
Comparison operators compare two values and return either `true` or `false`.

| Operator | Meaning | Example |
|----------|---------|---------|
| `==` | Equal (Value Only) | `10 == "10"` |
| `===` | Strict Equal (Value and Type) | `10 === "10"` |
| `!=` | Not Equal (Value Only) | `10 != 5` |
| `!==` | Strict Not Equal | `10 !== "10"` |
| `>` | Greater Than | `10 > 5` |
| `<` | Less Than | `5 < 10` |
| `>=` | Greater Than or Equal | `10 >= 10` |
| `<=` | Less Than or Equal | `5 <= 10` |

### Example
```javascript
let a = 10;
let b = "10";

console.log(a == b);
console.log(a === b);
console.log(a != b);
console.log(a !== b);
```

### Output
```
true
false
false
true
```

> **Note:** Prefer using `===` and `!==` because they compare both the **value** and the **data type**, making your code more reliable.

# 🔗 4️⃣ Logical Operators
Logical operators are used to combine or reverse conditions.

| Operator | Meaning | Example |
|----------|---------|---------|
| `&&` | AND | `a > 5 && a < 20` |
| `||` | OR | `a > 20 || a < 5` |
| `!` | NOT | `!(a > 5)` |

### Example
```javascript
let age = 20;

console.log(age > 18 && age < 30);
console.log(age > 18 || age < 10);
console.log(!(age > 18));
```

### Output
```
true
true
false
```

# ➕➖ 5️⃣ Increment & Decrement Operators
These operators increase or decrease a variable by **1**.

| Operator | Meaning |
|----------|---------|
| `++` | Increment by 1 |
| `--` | Decrement by 1 |

## Increment Example
```javascript
let x = 5;

x++;
console.log(x);
```

Output:
```
6
```

## Decrement Example
```javascript
let x = 5;

x--;
console.log(x);
```

Output:
```
4
```

# 📌 Pre-Increment vs Post-Increment

## Post-Increment (`x++`)
Returns the current value first, then increments it.

```javascript
let x = 5;

console.log(x++);
console.log(x);
```

Output:
```
5
6
```

## Pre-Increment (`++x`)
Increments the value first, then returns it.

```javascript
let x = 5;

console.log(++x);
console.log(x);
```

Output:
```
6
6
```

# 📌 Pre-Decrement vs Post-Decrement

## Post-Decrement (`x--`)
Returns the current value first, then decrements it.

```javascript
let x = 5;

console.log(x--);
console.log(x);
```

Output:
```
5
4
```

## Pre-Decrement (`--x`)
Decrements the value first, then returns it.

```javascript
let x = 5;

console.log(--x);
console.log(x);
```

Output:
```
4
4
```
