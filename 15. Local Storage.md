# 📘 Local Storage in JavaScript

# 🌟 What is Local Storage?
**Local Storage** is a browser feature that allows websites to store data on the user's computer.

The stored data:
- Remains after refreshing the page.
- Remains even after closing and reopening the browser.
- Stays until it is manually removed or cleared.

> **Simple Understanding:** Local Storage is like a **small database inside the browser**.

# 📂 Why is Local Storage Important?

Local Storage is commonly used to:

- ✅ Save user information
- ✅ Save website settings (Dark Mode, Language, Theme)
- ✅ Remember login information
- ✅ Save form data
- ✅ Store offline application data

# 📌 Features of Local Storage

- ✔ Stores data as **key-value pairs**
- ✔ Data does not expire automatically
- ✔ Stores **only strings**
- ✔ Approximately **5 MB** storage limit per domain
- ✔ Accessible only from the same website (same origin)

# 🧾 Local Storage Methods

| Method | Purpose |
|---------|---------|
| `setItem()` | Stores data |
| `getItem()` | Retrieves data |
| `removeItem()` | Removes a specific item |
| `clear()` | Removes all stored data |

# 1️⃣ `setItem()`

## Use
Stores data in Local Storage.

## Syntax

```javascript
localStorage.setItem("key", "value");
```

## Example

```javascript
localStorage.setItem("name", "John");
```

The value `"John"` is stored with the key `"name"`.

# 2️⃣ `getItem()`

## Use
Retrieves data from Local Storage.

## Syntax

```javascript
localStorage.getItem("key");
```

## Example

```javascript
let name = localStorage.getItem("name");

console.log(name);
```

### Output

```
John
```

# 3️⃣ `removeItem()`

## Use
Removes a specific item from Local Storage.

## Syntax

```javascript
localStorage.removeItem("key");
```

## Example

```javascript
localStorage.removeItem("name");
```

The item stored with the key `"name"` is removed.

# 4️⃣ `clear()`

## Use
Removes **all** data stored in Local Storage for the current website.

## Syntax

```javascript
localStorage.clear();
```

## Example

```javascript
localStorage.clear();
```

All stored data is deleted.

# ⭐ Local Storage Stores Only Strings

Local Storage can store only **string values**.

To store objects or arrays, convert them into JSON strings using `JSON.stringify()`.

# 📦 Store an Object

```javascript
let student = {
    name: "John",
    age: 20
};

localStorage.setItem(
    "student",
    JSON.stringify(student)
);
```

# 📥 Retrieve an Object

```javascript
let data = JSON.parse(
    localStorage.getItem("student")
);

console.log(data.name);
```

### Output

```
John
```

# 🔄 Update Stored Data

Retrieve the object, modify it, and store it again.

```javascript
let student = JSON.parse(
    localStorage.getItem("student")
);

student.age = 25;

localStorage.setItem(
    "student",
    JSON.stringify(student)
);

console.log(student.age);
```

### Output

```
25
```

# 📌 Store an Array

```javascript
let colors = ["Red", "Green", "Blue"];

localStorage.setItem(
    "colors",
    JSON.stringify(colors)
);
```

## Retrieve the Array

```javascript
let colors = JSON.parse(
    localStorage.getItem("colors")
);

console.log(colors);
```

### Output

```
["Red", "Green", "Blue"]
```

# 📌 View Local Storage in Browser

To view Local Storage in Google Chrome:

1. Open the webpage.
2. Right-click and select **Inspect**.
3. Open the **Application** tab.
4. Expand **Local Storage**.
5. Select your website.

You can now view all stored key-value pairs.

# 📌 Local Storage vs Session Storage

| Local Storage | Session Storage |
|---------------|-----------------|
| Data remains after closing the browser | Data is removed when the browser tab is closed |
| No expiration time | Exists only for the current browser session |
| Approximately 5 MB storage | Approximately 5 MB storage |
| Used for long-term storage | Used for temporary storage |
