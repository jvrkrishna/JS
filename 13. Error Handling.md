# 📘 Error Handling in JavaScript

# 🌟 What is Error Handling?
**Error handling** is the process of detecting and handling runtime errors in a JavaScript program.

It prevents the program from stopping unexpectedly and allows you to display user-friendly error messages.

### Benefits of Error Handling
- ✅ Prevents the program from crashing
- ✅ Displays meaningful error messages
- ✅ Makes debugging easier
- ✅ Improves the user experience

# 📂 Types of Errors in JavaScript

## 1️⃣ Syntax Error
A **Syntax Error** occurs when the JavaScript code does not follow the correct syntax.

### Example

```javascript
console.log("Hello"
```

### Reason
```
Missing closing parenthesis.
```

# 2️⃣ Runtime Error
A **Runtime Error** occurs while the program is executing.

### Example

```javascript
let x = y + 5;
```

### Reason
```
y is not defined.
```

# 3️⃣ Logical Error
A **Logical Error** occurs when the program runs without errors but produces an incorrect result.

### Example

```javascript
let length = 10;
let width = 5;

let area = length + width; // Incorrect

console.log(area);
```

### Output
```
15
```

The correct formula should be:

```javascript
let area = length * width;
```

Output:
```
50
```

# 🧾 `try...catch` Statement

The `try...catch` statement allows you to handle errors without stopping the program.

## Syntax

```javascript
try {
    // Code that may produce an error
}
catch (error) {
    // Code to handle the error
}
```

## Example

```html
<!DOCTYPE html>
<html>
<body>

<button onclick="runCode()">Run Code</button>

<script>
function runCode() {

    try {
        let result = x + 5; // x is not defined
        console.log(result);
    }

    catch (error) {
        console.log("Error:", error.message);
        alert("An error occurred. Check the console.");
    }

    console.log("Program continues...");
}
</script>

</body>
</html>
```

### Output
```
Alert: An error occurred.
Console: Error: x is not defined
Program continues...
```

# ⭐ `try...catch...finally`

The `finally` block always executes, whether an error occurs or not.

## Syntax

```javascript
try {
    // Code
}
catch (error) {
    // Handle error
}
finally {
    // Always executes
}
```

## Example 1 – No Error

```html
<!DOCTYPE html>
<html>
<body>

<button onclick="runSuccess()">Run</button>

<script>
function runSuccess() {

    try {
        console.log("Try Block: Everything is fine.");
    }

    catch (error) {
        console.log("Catch Block");
    }

    finally {
        console.log("Finally Block: Always runs.");
    }
}
</script>

</body>
</html>
```

### Output
```
Try Block: Everything is fine.
Finally Block: Always runs.
```

## Example 2 – Error Occurs

```html
<!DOCTYPE html>
<html>
<body>

<button onclick="runError()">Run</button>

<script>
function runError() {

    try {
        let result = x + 5;
        console.log(result);
    }

    catch (error) {
        console.log("Error:", error.message);
    }

    finally {
        console.log("Finally Block: Always runs.");
    }
}
</script>

</body>
</html>
```

### Output
```
Error: x is not defined
Finally Block: Always runs.
```

# 🚨 `throw` Statement

The `throw` statement is used to create custom errors.

## Syntax

```javascript
throw "Error Message";
```

or

```javascript
throw new Error("Error Message");
```

> **Note:** Using `new Error()` is the recommended approach because it creates a proper Error object.

## Example

```html
<!DOCTYPE html>
<html>
<body>

<input type="number" id="ageInput" placeholder="Enter your age">

<button onclick="checkEligibility()">Check Eligibility</button>

<p id="result"></p>

<script>
function checkEligibility() {

    let age = parseInt(document.getElementById("ageInput").value);
    let result = document.getElementById("result");

    try {

        if (age < 18) {
            throw new Error("Not Eligible");
        }

        result.textContent = "You are Eligible!";
    }

    catch (error) {
        result.textContent = error.message;
    }
}
</script>

</body>
</html>
```

### Output

If age is less than 18:

```
Not Eligible
```

Otherwise:

```
You are Eligible!
```

# 📌 Error Object

When an error occurs, JavaScript creates an **Error Object**.

It contains useful information about the error.

## Common Properties

| Property | Description |
|----------|-------------|
| `name` | Name of the error |
| `message` | Description of the error |

## Example

```html
<!DOCTYPE html>
<html>
<body>

<button onclick="runCode()">Run Code</button>

<p id="output"></p>

<script>
function runCode() {

    let output = document.getElementById("output");

    try {
        let x = y + 1;
    }

    catch (error) {
        output.innerHTML =
            "Error Name: " + error.name + "<br>" +
            "Error Message: " + error.message;
    }

    console.log("Program continues...");
}
</script>

</body>
</html>
```

### Output

```
Error Name: ReferenceError
Error Message: y is not defined
```

# 📌 Common JavaScript Error Types

| Error Type | Description |
|------------|-------------|
| `SyntaxError` | Invalid JavaScript syntax |
| `ReferenceError` | Variable is not defined |
| `TypeError` | Invalid operation on a value |
| `RangeError` | Value is outside the allowed range |
| `URIError` | Invalid URI function usage |

## Example – ReferenceError

```javascript
console.log(userName);
```

Output

```
ReferenceError: userName is not defined
```

## Example – TypeError

```javascript
let number = 10;

number.toUpperCase();
```

Output

```
TypeError: number.toUpperCase is not a function
```
