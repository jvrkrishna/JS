# 📘 Variables, Data Types, Comments & Template Literals

# 🌟 What is a Variable?
A **variable** is used to store data values.

👉 Think of a variable as a **container** that stores information.

### Example
```javascript
var name = "John";
```

Here:
- `name` → Variable name
- `"John"` → Stored value

# 🧾 Rules for Naming Variables
### ✅ Valid Rules
- Can contain letters, numbers, `_`, and `$`
- Must start with a letter, `_`, or `$`
- Variable names are case-sensitive (`age` and `Age` are different)

### ❌ Invalid Rules
- Cannot start with a number
- Cannot use JavaScript keywords as variable names
- Cannot contain spaces

### ✅ Valid Examples
```javascript
var age;
var _total;
var $price;
var user1;
```

### ❌ Invalid Examples
```javascript
var 1name;
var var;
var first name;
```

# 📦 Ways to Declare Variables

## 1️⃣ `var` (Older Method)
```javascript
var age = 25;
```

**Characteristics:**
- Function scoped
- Can be redeclared
- Can be reassigned
- Avoid using `var` in modern JavaScript unless necessary

## 2️⃣ `let` (Recommended)
```javascript
let age = 25;
```

**Characteristics:**
- Block scoped
- Cannot be redeclared in the same scope
- Can be reassigned

## 3️⃣ `const` (Constant Value)
```javascript
const pi = 3.14;
```

**Characteristics:**
- Block scoped
- Cannot be redeclared
- Cannot be reassigned

> **Note:** A `const` variable must be initialized when it is declared.

```javascript
const pi = 3.14;
pi = 3.14159; // ❌ TypeError
```

# 📌 Difference Between `var`, `let`, and `const`

| Feature | var | let | const |
|---------|-----|-----|-------|
| Scope | Function | Block | Block |
| Redeclaration | ✅ Yes | ❌ No | ❌ No |
| Reassignment | ✅ Yes | ✅ Yes | ❌ No |
| Hoisted | ✅ Yes | ✅ Yes | ✅ Yes |
| Initial Value During Hoisting | `undefined` | TDZ | TDZ |

# 1️⃣ Scope Difference (`var` vs `let`)

## `var` → Function Scoped
A variable declared with `var` is accessible throughout the function in which it is declared.

```javascript
function testVar() {
    if (true) {
        var x = 10;
    }

    console.log(x); // ✅ 10
}

testVar();
```

## `let` → Block Scoped
A variable declared with `let` is accessible only inside the block (`{}`) where it is declared.

```javascript
function testLet() {
    if (true) {
        let y = 20;
    }

    console.log(y); // ❌ ReferenceError
}

testLet();
```

# 2️⃣ Hoisting Difference

Both `var` and `let` are hoisted, but they behave differently.

### `var`
```javascript
console.log(a);

var a = 5;
```

Output:
```
undefined
```

`var` is hoisted and initialized with `undefined`.

### `let`
```javascript
console.log(b);

let b = 10;
```

Output:
```
ReferenceError
```

`let` is hoisted but remains in the **Temporal Dead Zone (TDZ)** until it is declared.

# 3️⃣ Redeclaration Rules

## `var`
```javascript
var name = "Alex";
var name = "Sam";

console.log(name);
```

Output:
```
Sam
```

Redeclaration is allowed.

## `let`
```javascript
let age = 25;
let age = 30;
```

Output:
```
SyntaxError
```

Redeclaration is not allowed in the same scope.

# 4️⃣ Global Object Behaviour

When variables are declared globally in a browser:

- `var` becomes a property of the `window` object.
- `let` and `const` do not become properties of the `window` object.

```javascript
var a = 1;
let b = 2;

console.log(window.a); // 1
console.log(window.b); // undefined
```

# 5️⃣ Loop Example (Important)

## Using `var`
```javascript
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100);
}
```

Output:
```
3
3
3
```

## Using `let`
```javascript
for (let j = 0; j < 3; j++) {
    setTimeout(() => console.log(j), 100);
}
```

Output:
```
0
1
2
```

**Reason:** `let` creates a new variable for each iteration of the loop.

# 🔢 JavaScript Data Types

JavaScript has two categories of data types:

- Primitive Data Types
- Non-Primitive (Reference) Data Types

## Primitive Data Types

### 1️⃣ Number
```javascript
let age = 25;
let price = 99.99;
```

Represents both integers and decimal numbers.

### 2️⃣ String
```javascript
let name = "John";
let city = 'London';
```

Represents text.

### 3️⃣ Boolean
```javascript
let isActive = true;
let isAdmin = false;
```

Represents either `true` or `false`.

### 4️⃣ Undefined
```javascript
let x;
```

A variable that has been declared but not assigned a value.

### 5️⃣ Null
```javascript
let data = null;
```

Represents an intentional empty value.

### 6️⃣ BigInt
```javascript
let num = 12345678901234567890n;
```

Used for very large integers.

### 7️⃣ Symbol
```javascript
let id = Symbol("id");
```

Represents a unique value.

## Non-Primitive Data Type

### Object
```javascript
let student = {
    name: "John",
    age: 20
};
```

Objects store collections of related data.

# 💬 Comments

Comments are used to explain code. They are ignored by the JavaScript engine.

## Single-line Comment
```javascript
// This is a single-line comment
```

## Multi-line Comment
```javascript
/*
This is a
multi-line comment.
*/
```

# 🧵 Template Literals

Template literals provide an easier way to create strings.

Instead of using:
```javascript
""
''
```

Template literals use **backticks (` `)**.

## ✨ Advantages
- Insert variables directly into strings.
- Create multi-line strings easily.
- Improve code readability.

# 📌 String Interpolation

Use `${}` to insert variables or expressions inside a template literal.

```javascript
let name = "John";
let age = 20;

console.log(`My name is ${name} and I am ${age} years old.`);
```

Output:
```
My name is John and I am 20 years old.
```

# 📌 Multi-line String Example

```javascript
let message = `Welcome
to
JavaScript`;

console.log(message);
```

Output:
```
Welcome
to
JavaScript
```

# 🧪 Example: Template Literal

```html
<script>
let a = Number(prompt("Enter first value"));
let b = Number(prompt("Enter second value"));

document.write(`Sum of ${a} and ${b} is ${a + b}`);
</script>
```
