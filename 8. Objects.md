# 📘 Objects in JavaScript

# 🌟 What is an Object?
An **object** is a collection of related data stored as **key-value pairs**.

Objects are used to represent real-world entities by grouping related information together.

### Real-Life Example
A **student** can have the following properties:
- Name
- Age
- Grade

### JavaScript Object Example
```javascript
let student = {
    name: "John",
    age: 20,
    grade: "A"
};
```

# 📂 Object Structure

```javascript
let objectName = {
    key1: value1,
    key2: value2
};
```

In an object:
- **Key (Property)** → Name of the property.
- **Value** → Data stored in that property.

# 🔎 Accessing Object Properties

## 1️⃣ Dot Notation
Use the dot (`.`) operator to access object properties.

```javascript
let student = {
    name: "John",
    age: 20,
    grade: "A"
};

console.log(student.name);
console.log(student.age);
```

### Output
```
John
20
```

## 2️⃣ Bracket Notation
Use square brackets (`[]`) to access object properties.

```javascript
console.log(student["name"]);
console.log(student["age"]);
```

### Output
```
John
20
```

> **Note:** Bracket notation is useful when the property name is stored in a variable or contains spaces.

# ✏️ Modifying Object Properties
You can change the value of an existing property.

## Example

```javascript
let student = {
    name: "John",
    age: 20
};

student.age = 21;

console.log(student);
```

### Output
```
{ name: "John", age: 21 }
```

# ➕ Adding New Properties
New properties can be added at any time.

## Example

```javascript
let student = {
    name: "John",
    age: 20
};

student.city = "London";

console.log(student);
```

### Output
```
{ name: "John", age: 20, city: "London" }
```

# ➖ Deleting Properties
Use the `delete` operator to remove a property.

## Example

```javascript
let student = {
    name: "John",
    age: 20,
    grade: "A"
};

delete student.grade;

console.log(student);
```

### Output
```
{ name: "John", age: 20 }
```

# 🧪 Object Methods
Objects can also contain **functions**. A function inside an object is called a **method**.

## Example

```javascript
let person = {
    name: "John",

    greet: function() {
        console.log("Hello");
    }
};

person.greet();
```

### Output
```
Hello
```

# 📌 Using `this` Keyword
Inside an object method, the `this` keyword refers to the current object.

## Example

```javascript
let person = {
    name: "John",

    greet: function() {
        console.log("Hello " + this.name);
    }
};

person.greet();
```

### Output
```
Hello John
```

# 🔁 Looping Through an Object

## Using `for...in` Loop

The `for...in` loop is used to iterate through an object's properties.

```javascript
let student = {
    name: "John",
    age: 20,
    grade: "A"
};

for (let key in student) {
    console.log(key + ": " + student[key]);
}
```

### Output
```
name: John
age: 20
grade: A
```

# ⭐ Common Object Methods

| Method | Purpose |
|---------|---------|
| `Object.keys()` | Returns an array of property names |
| `Object.values()` | Returns an array of property values |
| `Object.entries()` | Returns an array of key-value pairs |
| `Object.hasOwn()` | Checks whether an object contains a property |

# 📌 `Object.keys()`

```javascript
let student = {
    name: "John",
    age: 20,
    grade: "A"
};

console.log(Object.keys(student));
```

### Output
```
["name", "age", "grade"]
```

# 📌 `Object.values()`

```javascript
console.log(Object.values(student));
```

### Output
```
["John", 20, "A"]
```

# 📌 `Object.entries()`

```javascript
console.log(Object.entries(student));
```

### Output
```
[
  ["name", "John"],
  ["age", 20],
  ["grade", "A"]
]
```

# 📌 Checking Whether a Property Exists

## Using `Object.hasOwn()`

```javascript
let student = {
    name: "John",
    age: 20
};

console.log(Object.hasOwn(student, "name"));
console.log(Object.hasOwn(student, "grade"));
```

### Output
```
true
false
```
