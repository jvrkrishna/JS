# 📘 DOM (Document Object Model)

# 🌟 What is the DOM?
**DOM (Document Object Model)** is a programming interface that allows JavaScript to access, modify, add, and remove HTML elements.

When a web page loads, the browser converts the HTML document into a **DOM Tree**. Each HTML element becomes an **object** that JavaScript can manipulate.

```
HTML Document
      │
      ▼
Browser Creates DOM Tree
      │
      ▼
JavaScript Can Access & Modify Elements
```

# 📂 Common DOM Selection Methods

| Method | Selects | Returns |
|--------|----------|---------|
| `getElementById()` | Element by ID | Single Element |
| `getElementsByClassName()` | Elements by Class | HTMLCollection |
| `getElementsByTagName()` | Elements by Tag | HTMLCollection |
| `querySelector()` | First Matching Element | Single Element |
| `querySelectorAll()` | All Matching Elements | NodeList |

# 1️⃣ `getElementById()`

## Use
- Selects an element using its unique `id`.
- Returns a single HTML element.
- Commonly used to change content, styles, attributes, or retrieve input values.

## Example 1 – Change Text

```html
<!DOCTYPE html>
<html>
<body>

<p id="demo">Hello</p>

<button onclick="changeText()">Change</button>

<script>
function changeText() {
    document.getElementById("demo").innerHTML = "Welcome";
}
</script>

</body>
</html>
```

### Output
```
Hello → Welcome
```

## Example

```html
<!DOCTYPE html>
<html>
<body>

<p id="demo">Hello</p>

<button onclick="changeText()">Change</button>

<script>
const messages = [
    "Hello",
    "Welcome",
    "Good Morning",
    "How are you?",
    "Thank You!"
];

let index = 0;

function changeText() {
    index = (index + 1) % messages.length; // Move to next message
    document.getElementById("demo").innerHTML = messages[index];
}
</script>

</body>
</html>
```

## Output on Each Click

| Click | Displayed Text |
|-------:|----------------|
| Initial | Hello |
| 1st Click | Welcome |
| 2nd Click | Good Morning |
| 3rd Click | How are you? |
| 4th Click | Thank You! |
| 5th Click | Hello (starts over) |

# 2️⃣ `getElementsByClassName()`

## Use
- Selects all elements with the same class name.
- Returns an **HTMLCollection**.
- Commonly used with loops.

## Example 1 – Change the First Element

```html
<!DOCTYPE html>
<html>
<body>

<p class="text">First</p>
<p class="text">Second</p>

<button onclick="changeFirst()">Change</button>

<script>
function changeFirst() {
    document.getElementsByClassName("text")[0].innerHTML = "Changed";
}
</script>

</body>
</html>
```

### Output
```
First → Changed
```

## Example 2 – Change All Text Colors

```html
<!DOCTYPE html>
<html>
<body>

<p class="item">Item 1</p>
<p class="item">Item 2</p>

<button onclick="changeAll()">Change Color</button>

<script>
function changeAll() {
    let items = document.getElementsByClassName("item");

    for (let i = 0; i < items.length; i++) {
        items[i].style.color = "blue";
    }
}
</script>

</body>
</html>
```

### Output
```
All items become blue.
```

## Example 3 – Hide the First Element

```html
<!DOCTYPE html>
<html>
<body>

<p class="box">Box 1</p>
<p class="box">Box 2</p>

<button onclick="hideBox()">Hide First</button>

<script>
function hideBox() {
    document.getElementsByClassName("box")[0].style.display = "none";
}
</script>

</body>
</html>
```

### Output
```
The first box disappears.
```

# 3️⃣ `getElementsByTagName()`

## Use
- Selects elements by their HTML tag name.
- Returns an **HTMLCollection**.
- Useful for modifying all elements of the same type.

## Example 1 – Change the First Paragraph

```html
<!DOCTYPE html>
<html>
<body>

<p>Hello</p>
<p>World</p>

<button onclick="changePara()">Change</button>

<script>
function changePara() {
    document.getElementsByTagName("p")[0].innerHTML = "Updated";
}
</script>

</body>
</html>
```

### Output
```
Hello → Updated
```

## Example 2 – Count Paragraphs

```html
<!DOCTYPE html>
<html>
<body>

<p>One</p>
<p>Two</p>

<button onclick="count()">Count</button>

<script>
function count() {
    let total = document.getElementsByTagName("p").length;
    alert(total);
}
</script>

</body>
</html>
```

### Output
```
Alert displays: 2
```

## Example 3 – Change All Headings

```html
<!DOCTYPE html>
<html>
<body>

<h1>Heading 1</h1>
<h1>Heading 2</h1>

<button onclick="changeAll()">Change</button>

<script>
function changeAll() {
    let headings = document.getElementsByTagName("h1");

    for (let i = 0; i < headings.length; i++) {
        headings[i].innerHTML = "New Heading";
    }
}
</script>

</body>
</html>
```

### Output
```
Both headings become "New Heading".
```

# 5️⃣ `querySelectorAll()`

## Use
- Selects **all matching elements**.
- Uses CSS selectors.
- Returns a **NodeList**.
- Commonly used with loops or `forEach()`.

## Example 1 – Change All Paragraphs

```html
<!DOCTYPE html>
<html>
<body>

<p class="text">One</p>
<p class="text">Two</p>

<button onclick="change()">Change</button>

<script>
function change() {
    let items = document.querySelectorAll(".text");

    items.forEach(function(item) {
        item.innerHTML = "Updated";
    });
}
</script>

</body>
</html>
```

## Example 2 – Add Borders

```html
<!DOCTYPE html>
<html>
<body>

<div>Box 1</div>
<div>Box 2</div>

<script>
let boxes = document.querySelectorAll("div");

boxes.forEach(function(box) {
    box.style.border = "2px solid black";
});
</script>

</body>
</html>
```

## Example 3 – Change a List Item

```html
<!DOCTYPE html>
<html>
<body>

<ul>
    <li class="item">Apple</li>
    <li class="item">Banana</li>
</ul>

<button onclick="change()">Change</button>

<script>
function change() {
    let items = document.querySelectorAll(".item");
    items[1].innerHTML = "Mango";
}
</script>

</body>
</html>
```

# ✏️ `innerHTML`

## Use
- Changes or replaces the HTML content inside an element.
- Can insert HTML tags.
- Commonly used to display dynamic content.

## Example 1 – Change Text

```html
<p id="demo">Old Text</p>

<script>
document.getElementById("demo").innerHTML = "New Text";
</script>
```

### Output
```
Old Text → New Text
```

## Example 2 – Insert HTML

```html
<div id="box"></div>

<script>
document.getElementById("box").innerHTML =
"<h3>Heading Added</h3><p>This is a paragraph.</p>";
</script>
```

## Example 3 – Display a Calculation

```html
<p id="result"></p>

<script>
let sum = 10 + 20;

document.getElementById("result").innerHTML = "Sum is: " + sum;
</script>
```

### Output
```
Sum is: 30
```

# ➕ `createElement()`

## Use
- Creates a new HTML element dynamically.
- Usually used with `appendChild()`.

## Example 1 – Add a Paragraph

```html
<!DOCTYPE html>
<html>
<body>

<button onclick="addPara()">Add Paragraph</button>

<script>
function addPara() {
    let p = document.createElement("p");
    p.innerHTML = "New Paragraph Added";

    document.body.appendChild(p);
}
</script>

</body>
</html>
```

## Example 2 – Add a List Item

```html
<!DOCTYPE html>
<html>
<body>

<ul id="list">
    <li>Item 1</li>
</ul>

<button onclick="addItem()">Add Item</button>

<script>
function addItem() {
    let li = document.createElement("li");
    li.innerHTML = "New Item";

    document.getElementById("list").appendChild(li);
}
</script>

</body>
</html>
```

## Example 3 – Create a Styled Box

```html
<!DOCTYPE html>
<html>
<body>

<button onclick="createBox()">Create Box</button>

<script>
function createBox() {
    let div = document.createElement("div");

    div.innerHTML = "New Box";
    div.style.backgroundColor = "lightblue";
    div.style.padding = "10px";

    document.body.appendChild(div);
}
</script>

</body>
</html>
```
