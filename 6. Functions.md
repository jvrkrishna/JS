# 📘 Functions in JavaScript

# 🌟 What is a Function?
A **function** is a reusable block of code designed to perform a specific task.

Functions execute only when they are **called (invoked)**.

Using functions makes programs more organized, reusable, and easier to maintain.

## Example
```javascript
function greet() {
    console.log("Hello Students");
}

greet();
```

### Output
```
Hello Students
```

# 📂 Why Use Functions?
Functions provide several advantages:

- ✅ Avoid repeating the same code
- ✅ Improve code organization
- ✅ Make programs easier to debug
- ✅ Increase code reusability
- ✅ Make programs easier to read and maintain

# 🧾 Function Syntax

```javascript
function functionName() {
    // Code to execute
}
```

- `function` → Keyword used to declare a function.
- `functionName` → Name of the function.
- `{ }` → Function body containing the code to execute.

# 🧪 Function Without Parameters
A function that does not receive any input values.

## Example
```javascript
function showMessage() {
    console.log("Welcome to JavaScript Class");
}

showMessage();
```

### Output
```
Welcome to JavaScript Class
```

# 🧪 Function With Parameters
Parameters are variables that receive values when a function is called.

## Syntax
```javascript
function functionName(parameter1, parameter2) {
    // Code
}
```

## Example
```javascript
function greet(name) {
    console.log("Hello " + name);
}

greet("John");
```

### Output
```
Hello John
```

## Multiple Parameters

```javascript
function add(a, b) {
    console.log(a + b);
}

add(10, 20);
```

### Output
```
30
```

# 🔁 Function With Return Value
The `return` statement sends a value back to the place where the function was called.

## Example
```javascript
function add(a, b) {
    return a + b;
}

let result = add(5, 3);

console.log(result);
```

### Output
```
8
```

> **Note:** A function stops executing immediately after a `return` statement.

# 📌 Difference Between Parameters and Arguments

| Parameters | Arguments |
|------------|-----------|
| Variables defined in the function declaration | Actual values passed when calling the function |
| Declared inside the function definition | Passed during the function call |

## Example
```javascript
function greet(name) {
    console.log("Hello " + name);
}

greet("John");
```

- `name` → Parameter
- `"John"` → Argument

# ⚡ Arrow Functions
Arrow functions provide a shorter syntax for writing functions.

## Syntax
```javascript
const functionName = (parameters) => {
    // Code
};
```

## Example
```javascript
const add = (a, b) => {
    return a + b;
};

console.log(add(5, 3));
```

### Output
```
8
```

# ⚡ Short Arrow Function
If the function contains only one `return` statement, the braces and `return` keyword can be omitted.

```javascript
const add = (a, b) => a + b;

console.log(add(10, 20));
```

### Output
```
30
```

const calculate = (a, b) => ({
    sum: a + b,
    difference: a - b
});

console.log(calculate(10, 20));

### Output
```
{ sum: 30, difference: -10 }
```

# 📌 Default Parameters
Default parameters are used when no argument is provided during the function call.

## Example
```javascript
function greet(name = "Student") {
    console.log("Hello " + name);
}

greet();
greet("John");
```

### Output
```
Hello Student
Hello John
```

# 📌 Function Expression
A function can also be stored in a variable.

## Syntax
```javascript
const variableName = function() {
    // Code
};
```

## Example
```javascript
const greet = function() {
    console.log("Hello");
};

greet();
```

### Output
```
Hello
```

# 📌 Anonymous Function
A function without a name is called an **anonymous function**.

Anonymous functions are commonly used in function expressions.

## Example
```javascript
const add = function (a, b) {
    return a + b;
};

console.log(add(10, 20));
```

# 📌 Function Scope
Variables declared inside a function are accessible only within that function.

## Example
```javascript
function test() {
    let message = "Hello";
    console.log(message);
}

test();
```

### Output
```
Hello
```

Trying to access `message` outside the function will result in a `ReferenceError`.
