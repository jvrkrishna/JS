# 📘 ES6 Features (Modern JavaScript)

# 🌟 What is ES6?
**ES6 (ECMAScript 2015)** is a major update to JavaScript that introduced many modern features.

These features make JavaScript:
- ✅ Easier to read
- ✅ Shorter to write
- ✅ More powerful
- ✅ Easier to maintain

> **Note:** Modern JavaScript (ES6+) is supported by all modern browsers and is widely used in web development.

# 📂 Important ES6 Features

1. `let` and `const`
2. Arrow Functions
3. Template Literals
4. Destructuring
5. Spread Operator (`...`)
6. Rest Parameter (`...`)

# 1️⃣ `let` and `const`

## `let`
Variables declared with `let` can be reassigned.

```javascript
let age = 20;

age = 25;

console.log(age);
```

### Output
```
25
```

## `const`
Variables declared with `const` cannot be reassigned.

```javascript
const pi = 3.14;

console.log(pi);
```

Attempting to change its value results in an error.

```javascript
const pi = 3.14;

pi = 3.14159; // ❌ TypeError
```

> **Note:** `const` variables must be initialized when they are declared.

# 📌 Difference Between `let` and `const`

| `let` | `const` |
|--------|----------|
| Can be reassigned | Cannot be reassigned |
| Block scoped | Block scoped |
| Used for changing values | Used for constant values |

# 2️⃣ Arrow Functions

Arrow functions provide a shorter syntax for writing functions.

## Normal Function

```javascript
function add(a, b) {
    return a + b;
}

console.log(add(5, 3));
```

### Output
```
8
```

## Arrow Function

```javascript
const add = (a, b) => a + b;

console.log(add(5, 3));
```

### Output
```
8
```

## Arrow Function with One Parameter

```javascript
const square = number => number * number;

console.log(square(5));
```

### Output
```
25
```

> **Note:** If there is only one parameter, parentheses are optional.

# 3️⃣ Template Literals

Template literals use **backticks (` `)** instead of single or double quotes.

They make it easy to insert variables into strings.

## Example

```javascript
let name = "John";

console.log(`Hello ${name}`);
```

### Output
```
Hello John
```

## Multiple Variables

```javascript
let name = "John";
let age = 20;

console.log(`My name is ${name} and I am ${age} years old.`);
```

### Output
```
My name is John and I am 20 years old.
```

# 4️⃣ Destructuring

Destructuring allows you to extract values from arrays or objects into separate variables.

## Array Destructuring

```javascript
let colors = ["Red", "Green", "Blue"];

let [first, second, third] = colors;

console.log(first);
console.log(second);
console.log(third);
```

### Output
```
Red
Green
Blue
```

## Object Destructuring

```javascript
let student = {
    name: "John",
    age: 20
};

let { name, age } = student;

console.log(name);
console.log(age);
```

### Output
```
John
20
```

# 5️⃣ Spread Operator (`...`)

The spread operator expands the elements of an array or object.

It is commonly used to:
- Copy arrays
- Combine arrays
- Copy objects
- Merge objects

## Copy an Array

```javascript
let arr1 = [1, 2, 3];

let arr2 = [...arr1];

console.log(arr2);
```

### Output
```
[1, 2, 3]
```

## Combine Arrays

```javascript
let arr1 = [1, 2];
let arr2 = [3, 4];

let arr3 = [...arr1, ...arr2];

console.log(arr3);
```

### Output
```
[1, 2, 3, 4]
```

## Copy an Object

```javascript
let student = {
    name: "John",
    age: 20
};

let copy = { ...student };

console.log(copy);
```

### Output
```
{ name: "John", age: 20 }
```

# 6️⃣ Rest Parameter (`...`)

The rest parameter allows a function to accept multiple arguments as an array.

## Syntax

```javascript
function functionName(...parameter) {

}
```

## Example

```javascript
function sum(...numbers) {
    return numbers.reduce((total, number) => total + number, 0);
}

console.log(sum(1, 2, 3, 4));
console.log(sum(5));
console.log(sum(10, 20));
console.log(sum(-1, 1));
console.log(sum());
```

### Output
```
10
5
30
0
0
```

> **Note:** The second argument (`0`) in `reduce()` is the initial value. It prevents an error when no arguments are passed.

# 📌 Without Rest Parameter

```javascript
function sum(a, b) {
    return a + b;
}

console.log(sum(1, 2));
console.log(sum(1, 2, 3));
```

### Output
```
3
3
```

Extra arguments are ignored because the function accepts only two parameters.

# 📌 Rules of Rest Parameter

## ✅ Correct

The rest parameter must be the last parameter.

```javascript
function example(a, b, ...rest) {
    console.log(rest);
}
```

## ❌ Incorrect

```javascript
function example(...rest, a) {

}
```

This results in a **SyntaxError**.

## ❌ Only One Rest Parameter

```javascript
function example(...a, ...b) {

}
```

This also results in a **SyntaxError**.

# 📌 Spread Operator vs Rest Parameter

Although both use `...`, they serve different purposes.

| Spread Operator | Rest Parameter |
|-----------------|----------------|
| Expands arrays or objects | Collects multiple arguments into an array |
| Used while calling a function or copying arrays/objects | Used while defining a function |
| Splits values | Combines values |

## Spread Operator Example

```javascript
let numbers = [10, 20, 30];

console.log(...numbers);
```

### Output
```
10 20 30
```

## Rest Parameter Example

```javascript
function display(...numbers) {
    console.log(numbers);
}

display(10, 20, 30);
```

### Output
```
[10, 20, 30]
```
